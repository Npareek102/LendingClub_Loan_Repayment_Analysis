Project: Lending Club Credit Risk Analysis

Goal:
Identify key factors influencing loan default risk.

Tools Used:
Python, Pandas, Matplotlib, Seaborn

Dataset:
Lending Club Accepted Loans Dataset

Key Findings:
• Default risk increases significantly from Grade A to Grade G.
• Higher credit scores correspond to lower default risk.
• Borrowers with higher debt-to-income ratios are more likely to default.
• Small business loans show the highest default rates.
